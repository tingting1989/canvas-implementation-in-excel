🎨 颜色预览列类型 - ColorPreviewType 演示

🎯 ColorPreviewType 核心功能

🎨 可视化颜色预览

将颜色值（hex/rgb/rgba）渲染为可视化的颜色块

📦 多格式支持

支持 HEX、RGB、RGBA、HSL、HSLA 以及 CSS 颜色名称

🖼️ 可选边框

颜色块可配置是否显示边框，便于在浅色背景上识别

📐 圆角定制

支持自定义圆角大小，打造不同风格的颜色块

🔒 数据验证

自动验证颜色值格式，无效颜色会显示错误提示

✨ 安全回退

无效颜色值会显示为 transparent，确保渲染安全

📖 使用说明

支持的颜色格式

  • HEX - #fff, #ff0000, #FF0000, #abcdef
  • RGB - rgb(255, 0, 0)
  • RGBA - rgba(255, 0, 0, 0.5)
  • HSL - hsl(0, 100%, 50%)
  • HSLA - hsla(0, 100%, 50%, 0.8)
  • CSS 颜色名称 - red, green, blue, transparent 等

配置选项

  • borderRadius - 颜色块的圆角大小 (默认: 4)
  • showBorder - 是否显示边框 (默认: true)

数据验证

  • 有效值 - 符合上述格式的颜色值
  • 空值处理 - 空单元格显示为空白
  • 无效回退 - 无效颜色显示为 transparent

渲染特性

  • 居中显示 - 颜色块在单元格中居中
  • 自适应大小 - 颜色块大小根据单元格尺寸自适应
  • 圆角裁剪 - 使用圆角矩形绘制
  • 边框高亮 - 可选的边框便于识别边界

适用场景

  • 🎨 设计系统 - 展示主题色、品牌色
  • 🖌️ 调色板 - 可视化颜色集合
  • 📋 样式配置 - 显示文本颜色、背景色
  • 🏷️ 标签管理 - 不同状态对应不同颜色
