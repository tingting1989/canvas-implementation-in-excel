📚 SearchPlugin API 参考

搜索
query(queryStr, options)
async query(queryStr: string, options?: SearchOptions): Promise<SearchResult[]>
执行搜索，返回匹配结果数组。支持大小写敏感、全词匹配、正则表达式及搜索范围选项。
const results = await plugin.query('技术部', { caseSensitive: false, wholeWord: false, useRegex: false, searchScope: 'all' });
导航
findNext()
findNext(): Promise<SearchResult|null>
导航到下一个搜索结果，自动滚动到对应单元格并高亮。对应快捷键 F3。
const result = await plugin.findNext(); console.log(result.row, result.col);
导航
findPrevious()
findPrevious(): Promise<SearchResult|null>
导航到上一个搜索结果。对应快捷键 Shift+F3。
const result = await plugin.findPrevious();
替换
replace(replaceStr)
replace(replaceStr: string): Promise<boolean>
替换当前选中的搜索结果。使用 SetCellCommand 记录历史，支持 Ctrl+Z 撤销。
const ok = await plugin.replace('研发部');
替换
replaceAll(replaceStr)
replaceAll(replaceStr: string): Promise<number>
替换所有匹配结果。使用 BatchCommand 组合为原子操作，仅占 1 个 undo 栈位置，支持一键 Ctrl+Z 撤销全部。
const count = await plugin.replaceAll('研发部'); console.log(`已替换 ${count} 处`);
UI 控制
show() / hide()
show(): void    hide(): void
显示/隐藏搜索面板。hide() 同时清除高亮和搜索状态。
plugin.show(); // 打开面板 plugin.hide(); // 关闭并清除
状态
getState()
getState(): Readonly<SearchState>
获取只读搜索状态，包含 query、results、currentIndex、options 等。
const state = plugin.getState(); state.getQuery(); // 当前查询字符串 state.getResults(); // 结果数组 state.getCurrentIndex(); // 当前索引
生命周期
enable() / disable()
enable(): void    disable(): void
启用/禁用插件。禁用后快捷键不再响应，高亮被清除。
plugin.disable(); // 临时禁用 plugin.enable(); // 恢复启用

⚙️ SearchPlugin 配置选项 (pluginOptions.search)

通过 pluginOptions.search 传入 init(options)，与 SearchPlugin.DEFAULT_OPTIONS 合并后生效。未传则使用默认值。

选项路径 类型 默认值 说明
enabled boolean true 插件是否启用。设为 false 时插件加载但不激活，需手动调用 enable()。
shortcutKey string "Control+f" 打开搜索面板的快捷键。使用 KeyboardEvent.code 格式，支持 "Control+f" / "Meta+f"（macOS）。
findNextKey string "F3" 查找下一个结果的快捷键。
findPrevKey string "Shift+F3" 查找上一个结果的快捷键。
maxResults number 10000 最大返回结果数。超出部分被截断，防止超大数据集导致性能问题。
skipNonTopLeftMergedCells boolean false 全部替换时是否跳过合并非主单元格。false=允许替换合并区任意单元格（推荐）；true=仅替换左上角主单元格。
🎨 highlightStyle — 搜索结果高亮样式
highlightStyle.backgroundColor string "rgba(255,255,0,0.3)" 所有匹配结果的背景色（半透明黄色）。
highlightStyle.currentBackgroundColor string "rgba(255,165,0,0.5)" 当前导航到的结果背景色（半透明橙色，突出显示）。
highlightStyle.borderColor string "#ff9800" 当前结果边框颜色。
highlightStyle.borderWidth number 2 当前结果边框宽度（px）。
🔍 defaultOptions — 搜索默认选项（可被 query() 的 searchOptions 覆盖）
defaultOptions.caseSensitive boolean false 是否区分大小写。
defaultOptions.wholeWord boolean false 是否全词匹配（仅匹配完整单词，非子串）。
defaultOptions.useRegex boolean false 是否将查询字符串作为正则表达式解析。
defaultOptions.searchScope string "all" 搜索范围："all" 全表 | "selection" 选区 | "column" 当前列 | "row" 当前行。
配置示例： 
   plugins: [
            "search",
        ],
                pluginOptions: {
    search: {
        enabled: true,
        shortcutKey: "Control+f",
        findNextKey: "F3",
        findPrevKey: "Shift+F3",
        maxResults: 10000,
        skipNonTopLeftMergedCells: false,
        highlightStyle: {
            backgroundColor: "rgba(255, 255, 0, 0.3)",
            currentBackgroundColor: "rgba(255, 165, 0, 0.5)",
            borderColor: "#ff9800",
            borderWidth: 2,
        },
        defaultOptions: {
            caseSensitive: false,
            wholeWord: false,
            useRegex: false,
            searchScope: "all",
        }
    }
}
