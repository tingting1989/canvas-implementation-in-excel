📖 什么是自定义渲染器？

自定义渲染器是 Canvas Spreadsheet 的核心扩展机制，允许你将普通的文本单元格转换为 丰富的可视化组件。通过继承 BaseColumnType 并实现 render() 方法， 你可以创建任何想象中的单元格类型！

💡 核心优势：
• 数据可视化：将抽象数据转为直观图形
• 交互增强：支持点击、悬停、键盘操作
• 高度可定制：颜色、尺寸、动画全部可控
• 性能优秀：基于 Canvas 原生渲染，60fps 流畅

🎯 内置渲染器一览

  • checkbox - ☑️ 布尔复选框（任务清单）
  • progressBar - ████████ 百分比进度条
  • starRating - ⭐⭐⭐⭐☆ 星级评分
  • sparkline - 📈 迷你折线图趋势
  • colorPreview - 🎨 颜色预览块
  • trafficLight - 🚦 交通灯状态 ⭐ 新增
⚠️ 本教程重点：
我们将以 TrafficLightType（交通灯状态渲染器） 为例， 手把手教你实现一个完整的、生产级别的自定义渲染器！

⚙️ 第二步：最小化示例代码

// ✨ 最简单的自定义渲染器（仅需 10 行代码！）
class MyRenderer extends BaseColumnType {
    get name() { return 'myRenderer'; }

    render(context) {
        const { ctx, x, y, width, height, value } = context;

        // 在这里绘制你的自定义内容
        ctx.fillStyle = '#4CAF50';
        ctx.fillRect(x, y, width, height);

        ctx.fillStyle = '#FFFFFF';
        ctx.font = 'bold 16px Arial';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.fillText(value || '', x + width/2, y + height/2);
    }
}

✨ 最佳实践 & 设计原则

✅ 推荐做法

  • 使用 Math.max/min 确保数值在有效范围内
  • 所有坐标使用 Math.round() 避免亚像素模糊
  • 使用 ctx.save()/restore() 保护绑定状态
  • 提供合理的默认配置和 fallback 值
  • 实现完整的 validate() 方法进行数据校验
  • 支持 options 参数实现高度可定制
  • 添加 JSDoc 注释提升代码可读性
  • 考虑响应式设计（根据单元格大小自适应）

❌ 应避免的问题

  • ❌ 忘记重置 ctx.globalAlpha 导致后续元素透明
  • ❌ 直接修改 context 的属性（应只读取）
  • ❌ 在 render() 中执行耗时操作（如网络请求）
  • ❌ 硬编码颜色、尺寸等常量（应使用 options）
  • ❌ 忽略边界情况（null/undefined/非法值）
  • ❌ 未实现 format() 导致显示异常
  • ❌ 过度复杂的绘制逻辑影响性能

🎬 实现平滑动画

通过 context.needsUpdate = true 和 requestAnimationFrame， 你可以为渲染器添加流畅的动画效果。以下是 TrafficLightType 的动画实现原理： 

// 1. 定义动画状态属性
#animationStartTime = null;
#targetState = null;
#animationOpacity = 1;

// 2. 启动动画（在 handleClick/handleKeydown 中调用）
#startAnimation(targetState) {
    this.#targetState = targetState;
    #animationStartTime = performance.now();
    #animationOpacity = 0.5;  // 从半透明开始
}

// 3. 更新动画状态（在 render() 开头调用）
#updateAnimation() {
    if (#animationStartTime === null) return 1;

    const elapsed = performance.now() - #animationStartTime;
    const progress = Math.min(elapsed / 250, 1);  // 250ms 持续时间

    // 使用 easeOutCubic 缓动函数
    const eased = 1 - Math.pow(1 - progress, 3);
    #animationOpacity = 0.5 + 0.5 * eased;

    if (progress >= 1) {
        #animationOpacity = 1;
        #animationStartTime = null;
    }

    return #animationOpacity;
}

// 4. 在 render() 末尾标记需要继续更新
if (#animationStartTime !== null) {
    context.needsUpdate = true;  // 触发下一帧重绘
}
💡 性能优化技巧：
• 使用 performance.now() 而非 Date.now()（更高精度）
• 缓动函数让动画更自然（推荐 easeOutCubic/easeInOutQuad）
• 动画持续时间建议 200-400ms（太长会感觉卡顿）

🎮 创建交互式渲染器

通过设置 isInteractive = true 并实现交互方法， 你的渲染器可以像原生控件一样响应用户操作：

必须实现的接口

接口 触发时机 返回值含义
handleClick(ctx, e) 鼠标单击 新值（更新单元格）或 null（忽略）
handleHover(ctx, e) 鼠标移入 true（需要重绘）或 false
handleMouseLeave() 鼠标移出 true（需要重绘）或 false
handleKeydown(e, val) 键盘按下 新值或 null（交由默认逻辑）
⚠️ 重要提示：
设置 isInteractive = true 后，KeyboardStrategy 会自动调用你的 handleKeydown() 方法，而不是使用默认的方向键导航行为。 这对于游戏控件、评分组件等非常有用！
