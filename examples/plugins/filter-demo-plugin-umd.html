📚 FilterPlugin API 参考

配置
filterableColumns (getter/setter)
get filterableColumns(): number[] | null set filterableColumns(cols: number[] | null)
获取或设置允许过滤的列索引数组。设为 null 表示允许所有列过滤；设为空数组 [] 表示禁用所有列过滤。
plugin.filterableColumns = [0, 2, 4]; const cols = plugin.filterableColumns;
面板控制
openDropdown(col, position)
openDropdown(col: number, position: {x: number, y: number}): void
在指定位置打开某列的筛选下拉面板。通常由表头筛选图标点击自动触发，也可编程式调用。
plugin.openDropdown(2, { x: 300, y: 80 });
面板控制
closeDropdown()
closeDropdown(): void
关闭当前打开的筛选下拉面板。
plugin.closeDropdown();
面板控制
isDropdownOpen()
isDropdownOpen(): boolean
检查筛选下拉面板是否处于打开状态。
if (plugin.isDropdownOpen()) { ... }
筛选管理
clearAllFilters()
clearAllFilters(): void
清除所有列的筛选条件，恢复显示所有数据行。
plugin.clearAllFilters();
列信息
getColumnType(colIndex)
getColumnType(colIndex: number): "text" | "numeric" | "date"
获取指定列的类型，默认为 "text"。列类型影响筛选值列表的排序方式（数值列按数值排序，日期列按日期排序）。
const type = plugin.getColumnType(1); // "numeric"
列信息
isColumnFilterable(colIndex)
isColumnFilterable(colIndex: number): boolean
检查指定列是否允许过滤。受 filterableColumns 配置控制。
if (plugin.isColumnFilterable(0)) { ... }
表头渲染
renderFilterIcon(container, col, hasActiveFilter)
renderFilterIcon(container: HTMLElement, col: number, hasActiveFilter: boolean): HTMLElement
在指定表头容器中渲染筛选图标。hasActiveFilter 控制图标是否显示为激活状态（漏斗高亮）。
plugin.renderFilterIcon(headerEl, 2, false);

⚙️ FilterPlugin 配置选项 (pluginOptions.filter)

通过 pluginOptions.filter 传入 init(options)，与 FilterPlugin.DEFAULT_OPTIONS 合并后生效。未传则使用默认值。

选项路径 类型 默认值 说明
enabled boolean true 插件是否启用。设为 false 时插件加载但不激活。
dropdownWidth number 240 筛选下拉面板宽度（像素）。
dropdownMaxHeight number 360 筛选下拉面板最大高度（像素），超出后内容区可滚动。
virtualScrollThreshold number 200 虚拟滚动阈值。当唯一值数量超过此值时启用虚拟滚动以优化性能。
filterableColumns number[] | null null 允许过滤的列索引数组。null 表示允许所有列；空数组 [] 表示禁用所有列。
columnTypes Object {} 列类型映射表，键为列索引，值为 "text" / "numeric" / "date"。
🕳️ nullValueHandling — 空值处理配置
nullValueHandling.displayAs string "(空白)" 空值在筛选值列表中的显示文本。
nullValueHandling.alwaysShowInList boolean true 是否始终在值列表中显示空值项（即使该列无空值）。
nullValueHandling.sortToEnd boolean true 是否将空值排序到值列表末尾。
nullValueHandling.treatBlankAsNull boolean true 是否将空白字符串视为空值。
nullValueHandling.trimWhitespace boolean true 比较前是否去除值的首尾空白字符。
🔧 conditionOperators — 条件模式操作符列表
conditionOperators string[] ["eq","neq","contains",...] 条件模式下可用的操作符数组。包含：eq（等于）、neq（不等于）、contains（包含）、notContains（不包含）、startsWith（开头是）、endsWith（结尾是）、gt（大于）、gte（大于等于）、lt（小于）、lte（小于等于）。
🎨 iconRenderer — 筛选图标渲染配置
iconRenderer.iconSize number 12 筛选图标的尺寸（像素）。
iconRenderer.iconPadding number 6 筛选图标与列头文本的间距（像素）。
配置示例： 
pluginOptions: {
    filter: {
        enabled: true,
        dropdownWidth: 240,
        dropdownMaxHeight: 360,
        virtualScrollThreshold: 200,
        filterableColumns: [0, 2, 4],
        columnTypes: {
                    0: "text",
                    1: "text",
                    2: "numeric",
        },
        nullValueHandling: {
            displayAs: "(空白)",
            alwaysShowInList: true,
            sortToEnd: true,
            treatBlankAsNull: true,
            trimWhitespace: true,
        },
        conditionOperators: ["eq", "neq", "contains", "notContains", "startsWith", "endsWith", "gt", "gte", "lt", "lte"],
        iconRenderer: {
            iconSize: 12,
            iconPadding: 6,
        }
    }
}
