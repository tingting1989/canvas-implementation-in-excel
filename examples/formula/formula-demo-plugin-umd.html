💡 使用说明

公式输入

  • 在单元格中输入以 = 开头的文本即可创建公式
  • 例如: =SUM(A1:A10), =IF(A1>100, "优秀", "一般")
  • 函数名不区分大小写

支持的运算符

  • 算术运算符: + (加), - (减), * (乘), / (除), ^ (幂)
  • 比较运算符: = (等于), <> (不等于), > (大于), < (小于), >= (大于等于), <= (小于等于)
  • 文本连接: & (连接文本)

范围引用

  • 单个单元格: A1
  • 连续范围: A1:B10
  • 整行/整列: 1:1, A:A

✨ 逻辑函数扩展（4→6）

⚡ XOR - 异或奇偶判定器

判断 TRUE 值数量是否为奇数。奇数个 TRUE 返回 TRUE，偶数个返回 FALSE。用于互斥条件判断和复杂逻辑组合场景。

=XOR(A>80, B<50) → 奇数个TRUE返回TRUE
  • 真值表：XOR(TRUE,FALSE)=TRUE, XOR(TRUE,TRUE)=FALSE
  • 应用：互斥选项判断、状态校验、奇偶校验
  • 参数：支持 1-255 个逻辑表达式

🔵 TRUE / 🔴 FALSE - 布尔常量

显式布尔值生成器：明确返回布尔常量 TRUE 或 FALSE。不接受任何参数，提高代码可读性，便于动态替换实现。

=IF(score>70, TRUE(), FALSE()) → 显式返回布尔值
  • 特点：不接受任何参数，提供参数返回 #VALUE!
  • 用途：开关控制、条件标记、代码规范统一
  • 优势：语义清晰，与其他函数风格一致

🔤 大小写转换

UPPER / LOWER：统一文本大小写格式，用于数据标准化、邮箱处理等场景。

=UPPER("hello") → "HELLO"
=LOWER("EMAIL") → "email"

🔗 文本连接

CONCAT / CONCATENATE：拼接多个文本字符串，支持范围引用和无限参数。

=CONCAT("Hello"," ","World") → "Hello World"

✂️ 字符截取

LEFT / RIGHT / MID：从文本的不同位置截取指定数量的字符，灵活提取子串。

=LEFT("Hello",3) → "Hel"
=MID("Hello",2,3) → "ell"

🔍 查找与替换

FIND / SEARCH / SUBSTITUTE：定位子串位置或批量替换文本内容。

=FIND("World","Hi") → 位置
=SEARCH("w","Hi") → 忽略大小写

📏 长度与清理

LEN / TRIM：计算字符长度并清除多余空格，数据清洗必备工具。

=LEN("Hello") → 5
=TRIM(" Hi ") → "Hi"

💎 格式化输出

TEXT：将数值转换为指定格式的文本，支持千分位、百分比等多种格式。

=TEXT(1234,"#,##0") → "1,234"
=TEXT(0.15,"0%") → "15%"

➕ SUMIF / SUMIFS - 条件求和

SUMIF对满足单个条件的单元格求和，SUMIFS支持多条件组合（AND关系）。支持数值比较、文本匹配、通配符等多种条件格式。

=SUMIF(B:B,"水果",E:E) → 水果类销售额总和
=SUMIFS(E:E,B:B,"北京",D:D,">500")
  • 支持条件：>、<、=、>=、<=、<>、*、?、精确匹配
  • 参数校验：SUMIFS要求奇数参数+范围长度一致
  • 应用场景：按类别统计、多维筛选汇总、复杂报表

🔢 COUNTIF / COUNTIFS - 条件计数

COUNTIF统计满足单个条件的数量，COUNTIFS支持多条件组合计数。自动忽略空值，支持通配符模糊匹配。

=COUNTIF(A:A,">80") → 大于80的数量
=COUNTIFS(B:B,"北京",C:C,">500")
  • 通配符：* (任意多个)、? (单个字符)
  • COUNTIFS：偶数参数要求+所有范围长度一致
  • 应用场景：数据质量检查、分类统计、复合筛选

🛡️ IFERROR - 万能错误捕捉器

捕获所有以#开头的错误值并返回替代值。包括 #N/A、#VALUE!、#REF!、#DIV/0! 等全部错误类型，提供统一的错误处理机制。

=IFERROR(A/B, 0) → 除零时返回0
=IFERROR(VLOOKUP(...), "未找到")
  • 捕获范围：#N/A、#VALUE!、#REF!、#DIV/0!、#NUM!等
  • 优势：一行代码处理所有可能的错误
  • 注意：可能掩盖真正的问题，需谨慎使用

🎯 IFNA - 精准N/A处理器

仅捕获#N/A这一种错误，比IFERROR更精确。其他错误正常传播便于调试，特别适合VLOOKUP/MATCH等查找类函数的错误处理。

=IFNA(VLOOKUP(...), "不存在")
=IFNA(MATCH(...), 0)
  • 精准定位：只处理"未找到"类的#N/A错误
  • 优势：不会掩盖其他类型的错误
  • 嵌套技巧：=IFERROR(IFNA(...), "其他错误") 分层处理
