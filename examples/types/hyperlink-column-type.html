🖥️ 超链接列表格展示

💡 操作提示：按住 Ctrl（Windows）或 Cmd（Mac）+ 点击超链接单元格可打开链接

📖 使用说明

基本操作

  • 打开链接：按住 Ctrl/Cmd + 点击超链接单元格 → 在新标签页打开
  • 编辑单元格：双击单元格 → 输入 URL 或"显示文本|URL"格式
  • 切换配置：调整参数 → 点击「应用配置」→ 表格自动更新
  • 添加数据：点击「添加测试数据」→ 自动生成一行随机数据

数据格式

📌 纯 URL：https://github.com → 显示为简化后的 URL

📌 对象格式：{ url: "https://github.com", text: "GitHub" } → 显示为自定义文本

📌 输入格式：GitHub|https://github.com → 解析为对象格式

验证规则

  • 空值：空字符串、undefined、null 均视为有效
  • URL 格式：必须以 http:// 或 https:// 开头
  • 对象格式：必须包含有效的 url 字段

Hooks 支持

  • BEFORE_OPEN_URL：链接打开前触发，返回 false 可阻止打开
  • AFTER_OPEN_URL：链接打开后触发，用于日志记录等

技术特性

  • 安全打开：使用 noopener,noreferrer 防止安全漏洞
  • 文本截断：过长 URL 自动截断并添加省略号
  • 样式继承：用户配置的样式优先级高于默认样式
  • 与隐式检测兼容：同时支持自动检测和显式声明
