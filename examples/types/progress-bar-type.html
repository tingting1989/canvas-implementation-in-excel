📊 进度条列类型 - ProgressBarType 演示

🎯 ProgressBarType 核心功能

📊 可视化进度条

将数值（0-100）渲染为彩色进度条，直观展示完成进度

🎨 智能颜色变化

根据进度自动变化颜色：低进度红色，中进度黄色，高进度绿色

✨ 渐变填充效果

进度条使用渐变填充，视觉效果更加美观

📝 百分比显示

默认在进度条上显示百分比数值，支持自定义开关

🔒 数据验证

自动验证输入值必须在 0-100 范围内，超出范围自动提示

⚙️ 高度可定制

支持自定义进度条高度、圆角、颜色等样式选项

📋 进度条预览

低进度 (20%) 需改进
中进度 (50%) 进行中
高进度 (80%) 接近完成
完成 (100%) 已完成
// ✨ ProgressBarType 使用示例 // ✅ 基础用法 { type: "progressBar", width: 200 } // ✅ 自定义颜色方案 { type: "progressBar", width: 200, options: { colors: { low: "#ff6b6b", medium: "#feca57", high: "#10ac84" } } } // ✅ 隐藏百分比文字 { type: "progressBar", width: 200, options: { showPercent: false } } // ✅ 自定义高度比例 { type: "progressBar", width: 200, options: { heightRatio: 0.8 } }

🖥️ 进度条表格展示

📖 使用说明

颜色阈值规则

  • 低进度 (0-29%) - 显示为红色/橙色，表示进度较低
  • 中进度 (30-69%) - 显示为黄色/橙色，表示进度适中
  • 高进度 (70-100%) - 显示为绿色，表示进展良好

配置选项

  • heightRatio - 进度条高度相对于单元格高度的比例 (0.3-0.9)
  • borderRadius - 进度条的圆角大小
  • showPercent - 是否在进度条上显示百分比文字
  • colors.low/medium/high - 不同进度阶段的颜色

数据验证

  • 有效值 - 0 到 100 之间的数字
  • 自动修正 - 小于 0 视为 0，大于 100 视为 100
  • 空值处理 - 空单元格显示为空白进度条

渲染特性

  • 渐变填充 - 进度条使用从深到浅的渐变效果
  • 圆角裁剪 - 进度条两端使用圆角
  • 居中对齐 - 百分比文字在单元格中居中显示
  • 轨道背景 - 未填充部分显示为浅灰色轨道
