📖 功能说明

三种使用方式

1️⃣ 列配置 autoFitRow
在 columns 中为指定列设置 autoFitRow: true，该列内容变化时自动调整所在行高度。适合备注、描述等长文本列。
2️⃣ 全局配置 autoRowHeight
设置 autoRowHeight: true，所有列内容变化时均触发行高自适应。适合全局多行文本场景。
3️⃣ 右键菜单
选中单元格或行头后右键，选择「自适应行高」或「所有行自适应行高」，一次性调整选区或全表行高。

配置项

配置项 类型 默认值 说明
autoRowHeight boolean false 全局行自适应高度开关
autoRowHeightMin number 28 行高最小值（px）
autoRowHeightMax number 500 行高最大值（px），防止极端值
columns[i].autoFitRow boolean false 列级行自适应开关，该列内容变化时触发

代码示例

// 方式一：列配置 const workbook = new CanvasSheet.Workbook(container, { columns: [ { type: 'text', width: 100 }, { type: 'textarea', width: 200, autoFitRow: true }, ], }); // 方式二：全局配置 const workbook = new CanvasSheet.Workbook(container, { autoRowHeight: true, autoRowHeightMin: 28, autoRowHeightMax: 500, }); // 方式三：运行时调用 API workbook.updateSettings({ autoRowHeight: true }); // 手动触发行自适应 const sheet = workbook.activeSheet; sheet.autoFitRowHeight(0, sheet.rowColManager.rowCount - 1);
