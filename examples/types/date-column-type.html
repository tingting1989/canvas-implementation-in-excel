📅 日期列类型 - DateColumnType 演示

🎯 DateColumnType 核心功能

📅 三合一类型

统一使用 type: "date"，通过 pattern 自动切换日期/时间/日期时间模式

📝 智能编辑器

纯日期使用原生日期选择器，带时间自动切换为文本编辑器

🔍 灵活解析

支持 YYYY-MM-DD、DD/MM/YYYY、HH:mm:ss、YYYY-MM-DD HH:mm:ss 等多种格式

✅ 范围验证

支持 min/max 配置，自动验证日期/时间是否在指定范围内

🎨 居中对齐

默认居中对齐，符合日期时间的阅读习惯

🔄 格式多样

支持 24h/12h 制、中英文月名、AM/PM 等丰富格式

📖 使用说明

编辑器说明

  • 纯日期（YYYY-MM-DD）：双击后弹出原生日期选择器，体验最佳
  • 带时间（HH:mm:ss）：双击后弹出文本编辑器，手动输入时间
  • 日期时间：双击后弹出文本编辑器，输入完整日期时间

输入格式示例

日期：2026-07-22、2026/07/22、22/07/2026、2026年07月22日

时间：14:30:00、14:30、2:30 PM、02:30:00 PM

日期时间：2026-07-22 14:30:00、2026/07/22 14:30

验证规则

  • 空值：空字符串、undefined、null 均视为有效
  • 无效日期：根据 allowInvalid 配置决定是否允许显示
  • 范围检查：时间模式下比较当日时间点，日期模式下比较完整日期

技术特性

  • 智能解析：自动识别多种常见日期时间格式
  • 居中对齐：默认居中对齐，符合日期时间的阅读习惯
  • 格式多样：支持 24h/12h 制、中英文月名、AM/PM 等
  • 类型统一：纯日期、纯时间、日期时间统一为 type: "date"
