📖 函数详细说明

逻辑函数
IF - 条件判断
=IF(logical_test, value_if_true, [value_if_false])
根据条件是否成立返回不同的值，可嵌套使用实现复杂逻辑。
=IF(A1>100,"优秀","一般")
=IF(A1="","未填写",A1)
逻辑函数
AND - 逻辑与
=AND(logical1, [logical2], ...)
所有条件都为 TRUE 时返回 TRUE，任一条件为 FALSE 时返回 FALSE。
=AND(TRUE,TRUE) 返回 TRUE
=AND(A1>0,B1<100) A1>0 且 B1<100
逻辑函数
OR - 逻辑或
=OR(logical1, [logical2], ...)
任一条件为 TRUE 时返回 TRUE，所有条件都为 FALSE 时返回 FALSE。
=OR(FALSE,FALSE,FALSE) 返回 FALSE
=OR(A1<0,B1>100) A1<0 或 B1>100
逻辑函数
NOT - 逻辑非
=NOT(logical)
反转参数的逻辑值：TRUE 变为 FALSE，FALSE 变为 TRUE。
=NOT(TRUE) 返回 FALSE
=NOT(AND(A1>0,B1<50))
