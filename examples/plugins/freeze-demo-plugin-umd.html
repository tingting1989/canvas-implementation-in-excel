🧊 冻结区域图解

冻结行固定在视口顶部，冻结列固定在视口左侧。滚动时四个区域独立渲染：

冻结行 × 冻结列
(scrollX=0, scrollY=0)
冻结行 × 可滚动列
(scrollY=0, 仅水平滚动)
可滚动行 × 冻结列
(scrollX=0, 仅垂直滚动)
可滚动区域
(正常滚动)

📚 FreezePlugin API 参考

冻结设置
freeze(rows, cols)
freeze(rows: number, cols: number): void
同时设置冻结行数和列数。便捷方法，一次调用同时修改行和列的冻结状态。始终触发 AFTER_FREEZE 钩子。
const freeze = workbook.getPlugin('freeze'); freeze.freeze(2, 1); // 冻结前2行 + 前1列
冻结设置
setFixedRowsTop(count)
setFixedRowsTop(count: number): void
设置顶部冻结行数。0 表示取消行冻结，负值自动归零。修改后自动触发重绘和钩子通知。
freeze.setFixedRowsTop(3); // 冻结前3行 freeze.setFixedRowsTop(0); // 取消行冻结
冻结设置
setFixedColumnsStart(count)
setFixedColumnsStart(count: number): void
设置左侧冻结列数。0 表示取消列冻结，负值自动归零。修改后自动触发重绘和钩子通知。
freeze.setFixedColumnsStart(2); // 冻结前2列 freeze.setFixedColumnsStart(0); // 取消列冻结
取消冻结
unfreeze()
unfreeze(): void
取消所有冻结，将冻结行数和列数同时归零。仅在之前存在冻结时触发 AFTER_UNFREEZE 钩子。
freeze.unfreeze(); // 一键取消所有冻结
状态查询
isFrozen()
isFrozen(): boolean
判断当前是否存在冻结（行或列任一 > 0 即返回 true）。
if (freeze.isFrozen()) { console.log('当前有冻结'); }
只读属性
fixedRowsTop / fixedColumnsStart
get fixedRowsTop(): number   get fixedColumnsStart(): number
获取当前顶部冻结行数 / 左侧冻结列数。无冻结时返回 0。
console.log(freeze.fixedRowsTop); // 2 console.log(freeze.fixedColumnsStart); // 1
生命周期
enable() / disable()
enable(): void   disable(): void
启用/禁用插件。禁用时清除所有冻结状态（行和列归零）并重新渲染。启用时恢复激活状态。
freeze.disable(); // 清除冻结，禁用插件 freeze.enable(); // 恢复激活（不自动恢复冻结配置）
生命周期
destroy()
destroy(): void
销毁插件。先禁用（清除冻结状态），再调用父类销毁清理所有注册资源。
freeze.destroy(); // 完全销毁

⚙️ FreezePlugin 配置选项 (pluginOptions.freeze)

选项路径 类型 默认值 说明
fixedRowsTop number 0 顶部冻结行数。仅接受正整数，0 或负值将被忽略。
fixedColumnsStart number 0 左侧冻结列数。仅接受正整数，0 或负值将被忽略。
配置示例： 
plugins: ["freeze"],
pluginOptions: {
    freeze: {
        fixedRowsTop: 1,
        fixedColumnsStart: 2
    }
}

🪝 钩子 (Hooks)

钩子名称 类型 参数 说明
afterFreeze after (fixedRowsTop, fixedColumnsStart) 冻结变更后触发，传递当前冻结行数和列数。
afterUnfreeze after 无 取消所有冻结后触发。
钩子使用示例： 
workbook.addHook('afterFreeze', (rows, cols) => {
    console.log(`冻结: ${rows} 行, ${cols} 列`);
});

workbook.addHook('afterUnfreeze', () => {
    console.log('已取消所有冻结');
});
