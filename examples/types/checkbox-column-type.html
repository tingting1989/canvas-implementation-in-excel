🎯 CheckboxColumnType 核心功能

☑️ 可视化复选框

将布尔值渲染为美观的可视化复选框，而非简单的 TRUE/FALSE 文字

🎨 自定义样式

支持自定义选中/未选中颜色、复选框大小、圆角等样式选项

📝 灵活输入

支持多种布尔值输入：true/false、yes/no、1/0、是/否

✨ 居中对齐

默认居中对齐，复选框在单元格中完美居中显示

🔒 禁用状态

支持禁用状态，禁用时复选框显示半透明效果

✓️ 对勾动画

选中时显示优雅的对勾图案，符合用户直觉

📖 使用说明

支持的输入格式

  • true / false - 英文布尔值
  • yes / no - 英文字符串
  • 1 / 0 - 数字
  • 是 / 否 - 中文
  • TRUE / FALSE - 大小写不敏感

配置选项

  • checkedColor - 选中时的填充颜色
  • uncheckedColor - 未选中时的边框颜色
  • checkMarkColor - 对勾颜色
  • size - 复选框相对于单元格的大小比例 (0.3-0.9)

渲染特性

  • 圆角矩形 - 使用圆角矩形绘制复选框
  • 对勾图案 - 选中时绘制优雅的对勾
  • 半透明禁用 - 禁用状态时降低透明度
  • 居中对齐 - 默认居中显示
