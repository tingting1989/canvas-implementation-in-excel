⚡ 响应式状态管理 - ReactiveStore 演示

🎯 ReactiveStore 核心功能

🔄 响应式 Proxy

基于 Proxy 实现深层嵌套对象的响应式追踪，自动收集依赖

👁️ 路径监听

支持精确路径监听（深浅路径匹配），灵活订阅状态变化

📦 批量更新

batch() API 合并多次修改为一次通知，避免重复渲染

🧮 计算属性

computed() 自动缓存结果，仅在依赖变化时重新计算

⏰ 调度器

支持自定义调度器，控制异步 watcher 执行时机

📸 状态快照

getStateSnapshot() 获取包含所有计算属性的完整状态

// ✨ ReactiveStore 基础使用 import { ReactiveStore } from './src/state/ReactiveStore.js'; const store = new ReactiveStore({ user: { name: '张三', age: 25 }, settings: { theme: 'dark', lang: 'zh-CN' } }); // 直接修改（自动触发监听器） store.state.user.name = '李四'; // 监听变化 store.watch('user.name', (newVal, oldVal) => { console.log(`用户名: ${oldVal} → ${newVal}`); }); // 计算属性 store.computed('user.isAdult', (state) => state.user.age >= 18); // 批量更新 store.batch(() => { store.state.user.name = '王五'; store.state.user.age = 30; store.state.settings.theme = 'light'; });

📖 使用说明

核心 API

  • state - 响应式状态代理，通过 Proxy 自动追踪读写
  • watch(path, fn) - 监听路径变化，返回取消监听函数
  • computed(path, getter) - 创建计算属性，自动缓存并追踪依赖
  • batch(fn) - 批量更新，合并多次修改为一次通知
  • flush() - 立即刷出所有异步任务
  • nextTick() - 返回 Promise，等待下一个调度周期
  • getStateSnapshot() - 获取包含所有计算属性的状态快照

路径匹配规则

  • 精确匹配 - "user.name" 只监听 user.name 变化
  • 父路径 - "user" 监听 user 下所有属性变化
  • 子路径 - "user.name.first" 监听 user.name.first 及更深路径

适用场景

  • 📊 电子表格状态管理 - 单元格数据、选区、滚动位置
  • 🎨 表单状态管理 - 多字段联动、验证状态
  • 🎮 游戏状态 - 分数、道具、角色属性
  • 📈 仪表盘 - 多个指标联动、实时数据更新
