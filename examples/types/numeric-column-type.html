🎯 NumericColumnType 核心功能

📊 多种格式化

支持千分位、小数、百分比、货币、科学计数法等多种显示格式

🔍 数值验证

自动检测无效数值，支持配置最小值和最大值范围限制

📝 智能解析

自动去除千分位逗号和空格，智能转换用户输入

📈 数值排序

支持升序/降序排序，非数字值自动排在最前

🎨 右对齐

默认右对齐显示，符合数字阅读习惯

⚙️ 灵活配置

支持自定义格式模式、范围限制、无效值处理等选项

🖥️ 数字格式化表格展示

📖 使用说明

基本操作

  • 编辑单元格：双击数字单元格 → 进入编辑模式 → 输入数值 → 按 Enter 确认
  • 切换格式：选择格式模式 → 点击「应用配置」→ 表格自动更新显示
  • 范围限制：设置最小值和最大值 → 超出范围会显示验证错误
  • 添加数据：点击「添加测试数据」→ 自动生成一行随机数据

格式化示例

原始值：12345.6789

千分位 (0,0.00)："12,345.68"

百分比 (0.00%)："1234567.89%"

货币 ($0,0.00)："$12,345.68"

科学计数法 (0.00E+00)："1.23E+04"

验证规则

  • 空值：空字符串、undefined、null 均视为有效
  • 非数字：根据 allowInvalid 配置决定是否允许
  • 范围检查：数值必须在 min 和 max 之间（如果配置了）

技术特性

  • 智能解析：自动去除千分位逗号和空格
  • 右对齐：默认右对齐显示，符合数字阅读习惯
  • 数值排序：支持升序/降序，非数字值排在最前
  • 格式化缓存：相同格式和值的组合会被缓存优化
