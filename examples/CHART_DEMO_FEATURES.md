# Canvas-Sheet 图表演示示例 - 功能说明

## 📊 示例文件
**文件位置**: `examples/chart-demo-umd.html`

## ✨ 新增功能特性

### 1. 🖼️ 图片导出功能

#### 1.1 导出选中图表为图片
- **功能**: 将当前选中的图表导出为高质量PNG图片
- **特点**: 
  - 2倍分辨率 (scale: 2)
  - 高质量重建 (rebuildHighQuality: true)
  - 自动生成文件名
- **使用**: 点击 "🖼️ 导出选中图表" 按钮

#### 1.2 批量导出所有图表 (ZIP格式)
- **功能**: 将工作表中的所有图表打包为ZIP文件下载
- **适用场景**: 需要一次性获取所有图表时
- **输出**: `charts_export.zip` (包含所有PNG图片)
- **使用**: 点击 "📦 导出所有图表(ZIP)" 按钮

#### 1.3 分别导出所有图表
- **功能**: 每个图表单独下载为独立的PNG文件
- **适用场景**: 需要单独使用每个图表时
- **使用**: 点击 "📁 分别导出所有图表" 按钮

#### 1.4 单个图表快速导出
- **功能**: 在图表列表中直接导出特定图表
- **使用**: 在图表列表项中点击 "🖼️ 导出" 按钮

### 2. 📊 Excel内嵌图片功能

#### 2.1 导出Excel (含图表图片)
- **功能**: 生成完整的.xlsx文件，图表作为内嵌图片
- **技术实现**:
  - 使用 ExcelJS 库创建Excel文件
  - 图表通过Canvas转换为PNG图片
  - 图片嵌入到对应的工作表位置
  - 保持原始图表的位置和尺寸信息
- **输出**: 包含数据和内嵌图表的Excel文件
- **使用**: 点击 "📊 导出Excel(含图表图片)" 按钮

#### 2.2 CSV格式导出
- **功能**: 纯数据导出，不包含样式和图表
- **适用场景**: 数据交换、导入其他系统
- **使用**: 点击 "📋 导出CSV" 按钮

### 3. 🎯 便捷操作功能

#### 3.1 一键添加所有图表类型
- **功能**: 快速创建5种不同类型的示例图表
- **包含类型**:
  - 柱状图 (Bar Chart)
  - 折线图 (Line Chart)
  - 饼图 (Pie Chart)
  - 面积图 (Area Chart)
  - 散点图 (Scatter Chart)
- **使用**: 点击 "🎯 添加所有类型" 按钮

#### 3.2 图表管理增强
- **实时计数**: 显示当前图表数量
- **快速操作**: 选择、删除、导出单个图表
- **状态显示**: 实时更新图表列表

## 🔧 技术实现细节

### 核心API调用

```javascript
// 获取插件实例
const exportPlugin = workbook.getPlugin('exportFile');
const chartPlugin = workbook.getPlugin('chart');

// 导出单个图表为图片
await exportPlugin.downloadChart(chartId, filename, {
    format: 'png',
    quality: 1.0,
    scale: 2,
    rebuildHighQuality: true
});

// 批量导出所有图表
await exportPlugin.downloadAllCharts({
    format: 'png',
    asZip: true,           // 打包为ZIP
    rebuildHighQuality: true
});

// 导出Excel (自动包含图表)
await exportPlugin.downloadFile('xlsx', {
    filename: 'report_with_charts',
    cellStyles: true,
    columnHeaders: true
});
```

### 图片质量参数

| 参数 | 值 | 说明 |
|------|-----|------|
| format | 'png' | 图片格式 (支持 png/jpeg/webp) |
| quality | 1.0 | 图片质量 (0-1, 仅jpeg/webp有效) |
| scale | 2 | 分辨率倍数 (2 = 2倍分辨率) |
| rebuildHighQuality | true | 是否重建高质量缓存 |

## 📋 使用流程

## 📝 注意事项

1. **首次导出**: 首次导出可能需要重建图表缓存，会稍慢
2. **大量图表**: 图表数量过多时，批量导出可能需要较长时间
3. **浏览器限制**: 某些浏览器对文件下载有大小限制
4. **内存使用**: 高分辨率导出会占用更多内存

## 🛠️ 故障排除

### 常见问题:

**Q: 导出失败提示 "ExportFilePlugin 未加载"**
A: 检查控制台是否有加载错误，确保dist/canvas-sheet.umd.js文件存在

**Q: 图表导出为空白图片**
A: 确保图表已经渲染完成（在可视区域内）

**Q: Excel文件中没有图表**
A: 确认工作表中确实有图表，且chart插件正常工作

**Q: 下载的ZIP文件无法打开**
A: 可能是导出过程中断，请重试或检查浏览器控制台错误
