🎨 自定义菜单项 (Custom Items)

通过 customItems 配置添加自定义菜单项。支持三种渲染方式，优先级：render > html > icon + label

字段 类型 必填 说明
key string 否* 菜单项唯一标识键。未设置时自动生成 custom_0, custom_1... *建议始终设置以确保稳定引用。
label string 否 菜单项显示文本。当 html 或 render 存在时被忽略。
icon string 否 图标 HTML/SVG 字符串，渲染在文本左侧。当 html 或 render 存在时被忽略。
html string 否 自定义 HTML 内容，设置后 label/icon 均被忽略。适合带样式、徽章的富文本菜单项。
render (el: HTMLElement) => void 否 自定义渲染函数，优先级最高。直接操作菜单项 DOM 元素，可注入任意组件（复选框、下拉等）。
action (row, col, sheet) => void 否 点击回调函数。参数为右键点击的行号、列号和 sheet 实例。
contexts string[] 否 出现的上下文类型列表。可选值："cell"、"rowHeader"、"colHeader"。默认 ["cell"]。
type string 否 设为 "separator" 表示分隔线，此时其他字段均被忽略。

📝 示例 1：纯文本自定义项

// 最简单的自定义项：label + action customItems: [ { key: "myAction", label: "我的操作", action: (row, col, sheet) => { console.log(`点击了 [${row}, ${col}]`); }, contexts: ["cell", "rowHeader"] } ]

🎨 示例 2：带 SVG 图标的菜单项

customItems: [ { key: "drawChart", label: "绘图", icon: `<svg viewBox="0 0 16 16" width="16" height="16"> <path d="M2 14L6 6L10 10L14 2" stroke="#4A90D9" fill="none" stroke-width="1.5"/> </svg>`, action: (row, col, sheet) => { /* 打开绘图面板 */ }, contexts: ["cell"] } ]

🌐 示例 3：自定义 HTML 内容（带徽章/样式）

customItems: [ { key: "advancedFilter", html: `<span style="color:#e74c3c">⚠</span> 高级筛选 <span style="font-size:11px;color:#999">Beta</span>`, action: (row, col, sheet) => { /* ... */ } } ]

🛠 示例 4：自定义渲染函数（最灵活，可注入任意组件）

customItems: [ { key: "toggleDraw", render: (el) => { el.style.display = "flex"; el.style.alignItems = "center"; el.style.gap = "8px"; const cb = document.createElement("input"); cb.type = "checkbox"; cb.id = "toggle-drawing"; el.appendChild(cb); const label = document.createElement("label"); label.textContent = "启用绘图模式"; label.htmlFor = "toggle-drawing"; el.appendChild(label); }, action: (row, col, sheet) => { /* ... */ } } ]

📏 示例 5：分隔线 + 多上下文组合

customItems: [ { type: "separator" }, // 分隔线 { key: "exportPdf", label: "导出 PDF", icon: `<svg>...</svg>`, contexts: ["cell", "rowHeader", "colHeader"] }, { key: "shareLink", label: "分享链接", contexts: ["cell"] // 仅单元格右键时显示 } ]

⚙️ ContextMenuPlugin 配置选项 (pluginOptions.contextMenu)

通过 pluginOptions.contextMenu 传入，与 ContextMenuPlugin.DEFAULT_OPTIONS 合并后生效。

选项路径 类型 默认值 说明
enabled boolean true 插件是否启用。设为 false 时插件加载但不激活。
closeOnClickOutside boolean true 点击菜单外部区域时是否自动关闭。设为 false 时仅能通过 Esc 键或选择菜单项后关闭。
closeOnEscape boolean true 按 Esc 键时是否自动关闭菜单。
zIndex number 10001 菜单面板的 z-index 层级。默认高于筛选/搜索面板(10001)，确保右键菜单在最上层。
dropdownWidth number 180 菜单面板最小宽度（像素）。
dropdownMaxHeight number 400 菜单面板最大高度（像素），超出后内容区可滚动。
📌 customItems — 自定义菜单项列表
customItems MenuItemConfig[] [] 自定义菜单项数组。每项支持 key, label, icon, html, render, action, contexts, type 字段。详见上方"自定义菜单项"章节。
🚫 hiddenItems — 隐藏内置菜单项（完全不渲染）
hiddenItems string[] [] 隐藏的内置菜单项键数组。被隐藏的项完全不渲染，用户看不到。例如 ["insertImage", "mergeCells"] 可隐藏图片和合并操作。
🔒 disabledItems — 禁用内置菜单项（灰色显示，不可点击）
disabledItems string[] [] 禁用的内置菜单项键数组。被禁用的项仍可见但灰色显示，不可点击（opacity: 0.45, cursor: not-allowed）。例如 ["deleteRow", "deleteCol"] 可禁用删除操作但保留提示。
完整配置示例： 
pluginOptions: {
    contextMenu: {
        enabled: true,
        closeOnClickOutside: true,
        closeOnEscape: true,
        zIndex: 10001,
        dropdownWidth: 180,
        dropdownMaxHeight: 400,
        hiddenItems: ["insertImage", "mergeCells"],
        disabledItems: ["deleteRow", "deleteCol"],
        customItems: [
            {
                key: "drawChart",
                label: "绘图",
                icon: '<svg viewBox="0 0 16 16" width="16" height="16"><path d="M2 14L6 6L10 10L14 2" stroke="#4A90D9" fill="none" stroke-width="1.5"/></svg>',
                action: (row, col, sheet) => { console.log("绘图", row, col); },
                contexts: ["cell"]
            },
            {
                key: "advancedFilter",
                html: '<span style="color:#e74c3c">⚠</span> 高级筛选 <span style="font-size:11px;color:#999">Beta</span>',
                action: (row, col, sheet) => { /* ... */ }
            },
            {
                type: "separator"
            },
            {
                key: "exportPdf",
                label: "导出 PDF",
                action: (row, col, sheet) => { /* ... */ },
                contexts: ["cell", "rowHeader", "colHeader"]
            }
        ]
    }
}

⌨️ 交互说明

右键单击单元格
显示单元格上下文菜单（最完整）
右键单击行标头
显示行操作菜单（插入/删除行等）
右键单击列标头
显示列操作菜单（插入/删除列等）
Esc
关闭右键菜单（可配置 closeOnEscape）
点击菜单外部
关闭右键菜单（可配置 closeOnClickOutside）
选择菜单项
执行对应操作并自动关闭菜单

📚 ContextMenuPlugin API 参考

生命周期
enable() / disable()
enable(): void    disable(): void
启用/禁用插件。禁用后右键不再弹出菜单。
plugin.disable(); // 临时禁用 plugin.enable(); // 恢复启用
生命周期
init(options) / destroy()
init(options?: Partial<ContextMenuPluginOptions>): void destroy(): void
初始化/销毁插件。init 会合并 DEFAULT_OPTIONS，destroy 清理所有资源。
plugin.init({ enabled: true, disabledItems: ["deleteRow"] }); plugin.destroy();
