🎨 自定义图表 (Custom Chart) 演示

📖 自定义图表说明

Canvas-Sheet 的图表系统支持三个层级的自定义：

🟢 第一层：样式自定义 (ChartStyle)

通过 style 配置项自定义标题、颜色、图例、网格、坐标轴标签、平滑曲线等视觉属性，适用于所有内置图表类型。

🟠 第二层：运行时动态修改

通过 ChartPlugin 的 updateChartStyle()、updateChartDataRange()、moveChart()、resizeChart() 等方法在运行时动态修改图表。

🟣 第三层：策略扩展 (BaseChartStrategy)

继承 BaseChartStrategy 并覆写 render()、hitTest()、formatTooltip() 等方法，创建全新的图表类型，通过 NativeChartRenderer.register() 注册。

🔵 交互自定义

覆写 hitTest() 自定义点击命中检测，覆写 formatTooltip() 和 formatDetail() 自定义 Tooltip 显示格式。

💡 提示: 点击上方按钮依次体验三种自定义方式。本示例将创建一个"水滴图 (Waterdrop)"作为自定义策略的演示，它以水滴形状展示数据占比。

📝 ChartStyle 可配置属性一览

// 图表样式配置接口 (ChartStyle) interface ChartStyle { // --- 通用属性 --- title?: string; // 图表标题文本 showLegend?: boolean; // 是否显示图例 (默认 true) showGrid?: boolean; // 是否显示网格线 (默认 true) showTooltip?: boolean; // 是否显示 Tooltip (默认 true) colors?: string[]; // 系列颜色列表 (覆盖默认9色) ignoreHiddenData?: boolean; // 是否忽略隐藏行/列 // --- 折线图/面积图 --- fill?: boolean; // 是否填充区域 (面积图) smooth?: boolean; // 是否使用平滑曲线 // --- 坐标轴 --- xAxisLabel?: string; // X 轴标签文本 yAxisLabel?: string; // Y 轴标签文本 // --- 仪表盘 --- min?: number; // 自定义最小值 max?: number; // 自定义最大值 // --- 雷达图 --- indicators?: IndicatorConfig[]; // 各维度指标配置 // --- 热力图 --- showValue?: boolean; // 单元格内显示数值 cellPadding?: number; // 单元格内边距 }

📝 自定义策略示例代码

// 1. 继承 BaseChartStrategy 创建自定义策略 class WaterdropStrategy extends BaseChartStrategy { constructor() { super("waterdrop", "水滴图"); } // 2. 覆写 render() 实现绘制逻辑 render(ctx, data, area, style, yScale) { // ... 自定义 Canvas 绘制代码 ... } // 3. 覆写 isAxisFree() 声明无坐标轴 isAxisFree() { return true; } // 4. 覆写 hitTest() 自定义命中检测 hitTest(px, py, data, area, ...) { /* ... */ } // 5. 覆写 formatTooltip() 自定义提示格式 formatTooltip(hoverInfo) { /* ... */ } } // 6. 注册到渲染器 NativeChartRenderer.register(new WaterdropStrategy()); // 7. 通过 ChartPlugin 使用自定义图表 chartPlugin.addChart("waterdrop", dataRange, options);

📝 ChartPlugin 运行时 API

// 添加图表 (支持所有内置类型 + 自定义注册类型) chartPlugin.addChart(type, dataRange, options); // 便捷方法 (每种内置类型各一个) chartPlugin.addBarChart(dataRange, options); chartPlugin.addLineChart(dataRange, options); chartPlugin.addPieChart(dataRange, options); // ... addAreaChart, addScatterChart, addCandlestickChart, // addGaugeChart, addFunnelChart, addRadarChart, addHeatmapChart // 运行时动态修改 chartPlugin.updateChartStyle(chartId, { colors: [...], smooth: true }); chartPlugin.updateChartDataRange(chartId, { startRow, startCol, endRow, endCol }); chartPlugin.moveChart(chartId, anchorRow, anchorCol, offsetX, offsetY); chartPlugin.resizeChart(chartId, width, height); chartPlugin.removeChart(chartId);
