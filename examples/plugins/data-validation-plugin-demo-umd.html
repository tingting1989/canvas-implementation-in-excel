🔍 内置验证器

type: number
数值范围验证
验证数值是否在指定范围内，支持大小比较和相等性判断。
运算符: between, notBetween, greaterThan, lessThan, equalTo, notEqualTo, greaterThanOrEqual, lessThanOrEqual
type: text
文本长度验证
验证文本字符串的长度是否满足条件。
运算符: lengthBetween, lengthGreaterThan, lengthLessThan, lengthEqualTo
type: list
下拉列表验证
验证值是否在预定义选项列表中，支持静态数组和动态区域引用。
配置: source = ['选项1', '选项2', ...]
type: date
日期范围验证
验证日期是否在指定范围内，支持前后判断和相等性判断。
运算符: before, after, between, notBetween, equalTo, notEqualTo
type: time
时间范围验证
验证时间值是否在指定范围内。
运算符: before, after, between, notBetween
type: regex
正则表达式验证
根据正则模式验证文本，内置邮箱、手机号、身份证等预设。
配置: pattern = '^[a-z]+$' 或预设名 email, phoneCN, idCardCN, url
type: unique
唯一性验证
验证值在指定区域内是否唯一，适用于订单号、学号等场景。
无需运算符，自动排除当前编辑行
type: custom
自定义公式验证
通过公式表达式进行自定义验证逻辑。
配置: formula = '=A1>0'

📖 插件 API 参考

初始化
plugins 配置方式
plugins: ['dataValidation']
在 Workbook 构造时通过 plugins 数组启用数据验证插件，可通过 pluginOptions.dataValidation 传入初始规则。
new Workbook(canvas, { plugins: ['dataValidation'], pluginOptions: { dataValidation: { rules: [{ range: 'A:A', type: 'number', operator: 'greaterThan', value: 0 }], conflictStrategy: 'short-circuit' } } });
规则管理
setValidation
dv.setValidation(ruleOptions): string
添加验证规则，返回规则 ID。触发 BEFORE/AFTER_VALIDATION_RULE_CHANGE 钩子。
const id = dv.setValidation({ range: 'B2:B100', type: 'number', operator: 'between', value: [0, 10000], errorMessage: '请输入0-10000', errorStyle: 'stop', allowBlank: true });
规则管理
removeValidation
dv.removeValidation(ruleId): boolean
根据规则 ID 移除验证规则，返回是否成功。
dv.removeValidation(id); // true
规则管理
getRulesForCell / getAllRules / getRuleById
dv.getRulesForCell(row, col): Rule[]
查询规则：按单元格查询、获取全部、按 ID 查询。
dv.getRulesForCell(0, 0); dv.getAllRules(); dv.getRuleById('vr_xxx');
验证执行
validateCell
dv.validateCell(row, col, value): Promise<Result>
异步验证单个单元格的值，返回 ValidationResult 对象。
const r = await dv.validateCell(0, 0, 50); // r.valid, r.message, r.errorStyle
验证执行
validateRange
dv.validateRange(range): Promise<Report>
批量验证区域内所有单元格，返回统计报告。
const report = await dv.validateRange('A1:A100'); // report.total, report.valid, // report.invalid, report.results
导入导出
exportRules / importRules
dv.exportRules(): Object[]
导出规则为 JSON 数组（持久化），或从 JSON 数组导入规则。
const json = dv.exportRules(); localStorage.setItem('dv', JSON.stringify(json)); const ids = dv.importRules(json);
生命周期
enable / disable / destroy
dv.enable() / dv.disable() / dv.destroy()
启用/禁用/销毁插件。禁用时暂停拦截，销毁时释放所有资源。
dv.disable(); // 暂停验证 dv.enable(); // 恢复验证 dv.destroy(); // 彻底销毁
冲突策略
engine.conflictStrategy
dv.engine.conflictStrategy = 'short-circuit'
设置多规则冲突解决策略：short-circuit（首条失败即返回）、priority（末条决定）、aggregate（收集全部错误）。
dv.engine.conflictStrategy = 'aggregate';

⚙️ ValidationRule 配置项

必填
range + type
range: 'A1:A100', type: 'number'
range 指定目标区域（支持 "A:A" 整列、"1:1" 整行、"A1:B100" 区域）。type 指定验证类型。
条件
operator + value
operator: 'between', value: [0, 100]
operator 指定比较运算符，value 指定比较值。between/notBetween 时 value 为数组 [min, max]。
列表
source
source: ['选项A', '选项B']
type=list 时必填。静态数组或动态区域引用 '=Sheet1!$A$1:$A$10'。
正则
pattern
pattern: '^[a-z]+$'
type=regex 时必填。正则表达式字符串，也可使用 RegexValidator.PRESETS 中的预设名。
公式
formula
formula: '=A1>0'
type=custom 时必填。自定义公式表达式，返回真值表示验证通过。
错误提示
errorStyle + errorMessage
errorStyle: 'stop', errorMessage: '值无效'
errorStyle: stop（阻止输入）、warning（警告可继续）、information（仅提示）。errorMessage 自定义错误消息。
输入提示
inputMessage + inputTitle
inputMessage: '请输入正数', inputTitle: '提示'
选中单元格时显示的输入提示信息。
其他
allowBlank / showDropdown / priority
allowBlank: true, priority: 0
allowBlank 是否允许空值；showDropdown 是否显示下拉箭头（list 类型）；priority 规则优先级（越小越先执行）。
