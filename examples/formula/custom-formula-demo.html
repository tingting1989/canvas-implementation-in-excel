📖 如何自定义公式

第一步：导入注册表
从公式模块导入函数注册表
import { functionRegistry } from '@canvas-sheet/core';
第二步：注册自定义函数
使用 registry.register(函数名, 实现函数) 注册
// 简单函数：计算平方 registry.register('SQUARE', (args) => { const num = args[0]; return num * num; }); // 带上下文的函数：可访问其他工作表数据 registry.register('CROSS_SHEET_SUM', (args, ctx) => { const otherSheet = ctx.workbook.sheets.get('Sheet2'); return args[0] + 100; });
第三步：在单元格中使用
在单元格中输入以 = 开头的公式即可调用
// 在单元格中输入 =DOUBLE(A1) =SQUARE(B2) =CUSTOM_ADD(A1, B1)
第四步：查询和管理函数
可以使用以下方法查询和管理已注册的函数
registry.has('DOUBLE'); // 检查函数是否存在 registry.get('DOUBLE'); // 获取函数实现 registry.list(); // 列出所有函数 registry.getStats(); // 获取统计信息 registry.unregister('DOUBLE'); // 注销自定义函数

💡 内置自定义函数

以下是本演示页面预注册的自定义函数，可以在表格中使用：

DOUBLE - 两倍数值
=DOUBLE(number)
返回输入数值的两倍。简单的数学运算示例。
SQUARE - 平方
=SQUARE(number)
返回输入数值的平方。演示如何创建数学运算自定义函数。
CUSTOM_ADD - 加法
=CUSTOM_ADD(a, b)
返回两个数值的和。演示如何处理多个参数。
IS_POSITIVE - 判断正数
=IS_POSITIVE(number)
返回 TRUE 如果数值大于 0，否则返回 FALSE。演示条件判断。
PERCENTAGE - 百分比
=PERCENTAGE(value, total)
计算 value 占 total 的百分比。演示商务场景应用。
CONCAT_3 - 连接三个文本
=CONCAT_3(text1, text2, text3)
将三个文本连接成一个字符串。演示文本处理自定义函数。
