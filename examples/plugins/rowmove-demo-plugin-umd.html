🪝 生命周期钩子

RowMoveStrategy 在移动过程中触发两个钩子，可通过 workbook.addHook() 注册回调实现业务拦截。

钩子名称 触发时机 回调参数 说明
beforeRowMove 松开鼠标、移动前 (sourceRow, targetRow) 返回 false 可取消本次移动。用于权限校验、保护特定行等场景。
afterRowMove 移动完成后 (sourceRow, targetRow) 移动已生效，可用于同步外部数据源、记录日志、触发联动更新等。
💡 钩子使用示例： 
workbook.addHook('beforeRowMove', (sourceRow, targetRow) => {
  if (sourceRow === 0) {
    console.warn('表头行不可移动');
    return false;  // 取消移动
  }
});

workbook.addHook('afterRowMove', (sourceRow, targetRow) => {
  console.log(`行 ${sourceRow} 已移动到 ${targetRow}`);
});

📚 RowMovePlugin API 参考

生命周期
init(options)
init(options?: { enabled?: boolean }): void
初始化插件，调用 _createStrategy() 创建 RowMoveStrategy 并注册到 EventHandler（优先级 600）。设为 enabled: false 可初始禁用。
workbook.loadPlugin('rowMove', { enabled: false });
生命周期
destroy()
destroy(): void
销毁插件，清空策略引用，调用 super.destroy() 自动清理注册的策略和钩子。
plugin.destroy();
状态控制
enable()
enable(): void
启用插件及关联策略。启用后行头可响应拖拽移动事件。
plugin.enable(); console.log(plugin.enabled); // true
状态控制
disable()
disable(): void
禁用插件及关联策略。禁用后行头不响应拖拽，但正常选择仍可用。
plugin.disable(); console.log(plugin.isEnabled); // false
状态查询
PLUGIN_NAME (static)
static get PLUGIN_NAME(): "rowMove"
插件唯一标识符，用于 PluginManager 注册和 workbook.getPlugin() 查询。
const plugin = workbook.getPlugin( RowMovePlugin.PLUGIN_NAME );
模板方法
_createStrategy()
_createStrategy(): RowMoveStrategy
工厂方法（覆盖自 BaseMovePlugin），返回 RowMoveStrategy 实例。这是 RowMovePlugin 与 ColumnMovePlugin 的唯一区别。
// 内部实现 _createStrategy() { return new RowMoveStrategy(this.eventHandler); }
架构
addStrategy(name, strategy)
addStrategy(name: string, strategy: Strategy): void
将策略注册到 EventHandler。继承自 BasePlugin。BaseMovePlugin.init() 内部调用此方法注册移动策略。
// 内部调用（通常无需手动调用） this.addStrategy('rowMove', strategy);

⚙️ RowMovePlugin 配置选项 (pluginOptions.rowMove)

通过 pluginOptions.rowMove 传入 init(options)。

选项路径 类型 默认值 说明
enabled boolean true 插件是否默认启用。设为 false 时插件加载但不激活，需手动调用 enable()。
配置示例： 
pluginOptions: {
    rowMove: {
        enabled: true
    }
}
