🎯 TextColumnType 核心功能

📄 默认左对齐

文本内容默认左对齐显示，符合阅读习惯

✂️ 自动去空白

自动去除输入文本首尾的空白字符

📏 长度限制

支持配置最大长度限制，超过时自动提示

🔄 灵活配置

支持自定义对齐方式、最大长度等选项

✅ 空值处理

空字符串、undefined、null 均视为有效

🎨 样式继承

用户配置的样式优先级高于默认样式

// ✨ TextColumnType 使用示例 // 创建文本列配置 columns: [ { type: "text", width: 150, options: { maxLength: 100 // 最大长度限制 } }, { type: "text", width: 200, textAlign: "center" // 覆盖默认左对齐 }, { type: "text", width: 180, // style 配置项：直接设置列样式 style: { backgroundColor: "#f5f5f5", color: "#333333", fontWeight: "bold", fontSize: 14, fontFamily: "Microsoft YaHei" } } ] // 支持的 options 配置项 const options = { maxLength: 50, // 最大字符数限制 }; // 支持的 style 配置项 const styleOptions = { textAlign: "left", // 对齐方式: left/center/right backgroundColor: "#f0f0f0", // 背景颜色 color: "#333", // 文字颜色 fontWeight: "bold", // 字体粗细 fontSize: 14, // 字体大小 fontFamily: "Microsoft YaHei", // 字体 };

🖥️ 文本列表格展示

📖 使用说明

基本操作

  • 编辑单元格：双击文本单元格 → 进入编辑模式 → 输入文本 → 按 Enter 确认
  • 切换对齐：选择对齐方式 → 点击「应用配置」→ 表格自动更新
  • 长度限制：设置最大长度 → 超出时显示验证错误
  • 添加数据：点击「添加测试数据」→ 自动生成一行随机数据

核心功能

✂️ 自动去空白：输入 " Hello World " → 存储为 "Hello World"

📏 长度验证：超过 maxLength 限制时显示错误提示

🎨 默认左对齐：文本默认左对齐，可通过 {type:'text', style:{textAlign: "center"}} 配置覆盖

验证规则

  • 空值：空字符串、undefined、null 均视为有效
  • 长度限制：超过 maxLength 时返回错误消息
  • trim 处理：parse() 时自动去除首尾空白

技术特性

  • 类型安全：所有输入都转换为字符串类型
  • 样式优先级：用户配置 > 类型默认 > 全局默认
  • 国际化支持：支持任意 Unicode 字符
  • 回退类型：未知类型自动 fallback 到 text
