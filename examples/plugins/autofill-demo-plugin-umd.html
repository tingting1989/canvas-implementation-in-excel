🖱️ 交互操作说明

选中单元格
点击单元格选中，选区右下角出现绿色填充手柄

Ctrl+Z

🧠 智能序列识别

AutoFillStrategy 会自动分析源数据模式，智能推断填充规则。以下是支持的序列类型：

序列类型 源数据示例 填充结果示例 识别规则
等差数列 1, 2, 3 4, 5, 6, 7, ... 检测步长 step=1，线性递增
等差数列（大步长） 10, 20, 30 40, 50, 60, ... 检测步长 step=10
文本+数字 Item1, Item2 Item3, Item4, Item5, ... 分离文本前缀和数字后缀，数字递增
纯文本复制 "已完成" "已完成", "已完成", ... 无可识别模式，直接复制源值
单值数列 5 5, 5, 5, ...（步长=0） 单个数值视为步长=0，复制
负步长数列 10, 8, 6 4, 2, 0, -2, ... 检测步长 step=-2，线性递减

📚 AutoFillPlugin API 参考

生命周期
init(options)
init(options?: { enabled?: boolean }): void
初始化插件，创建 AutoFillStrategy 并注册到 EventHandler（优先级 90）。设为 enabled: false 可初始禁用。
workbook.loadPlugin('autoFill', { enabled: false });
生命周期
destroy()
destroy(): void
销毁插件，释放策略引用，从 EventHandler 移除策略。销毁后不可再使用。
plugin.destroy();
状态控制
enable()
enable(): void
启用插件及关联策略。启用后填充手柄响应拖拽事件。
plugin.enable(); console.log(plugin.isEnabled); // true
状态控制
disable()
disable(): void
禁用插件及关联策略。禁用后填充手柄仍可见但不响应拖拽，不影响其他鼠标操作。
plugin.disable(); console.log(plugin.isEnabled); // false
状态查询
isEnabled (getter)
get isEnabled(): boolean
获取插件当前启用状态。继承自 BasePlugin。
if (plugin.isEnabled) { console.log('自动填充已激活'); }
状态查询
PLUGIN_NAME (static)
static get PLUGIN_NAME(): "autoFill"
插件唯一标识符，用于 PluginManager 注册和 workbook.getPlugin() 查询。
const plugin = workbook.getPlugin( AutoFillPlugin.PLUGIN_NAME );
架构
addStrategy(name, strategy)
addStrategy(name: string, strategy: Strategy): void
将策略注册到 EventHandler。继承自 BasePlugin。AutoFillPlugin 内部注册名为 "autoFill" 的策略。
// 内部调用（通常无需手动调用） this.addStrategy('autoFill', strategy);
架构
eventHandler (getter)
get eventHandler(): EventHandler
获取工作表的事件处理器实例。继承自 BasePlugin，用于策略创建时传入。
const eh = plugin.eventHandler; // AutoFillStrategy 依赖此实例

⚙️ AutoFillPlugin 配置选项 (pluginOptions.autoFill)

通过 pluginOptions.autoFill 传入 init(options)。当前版本支持以下选项，未来可扩展自定义填充模式。

选项路径 类型 默认值 说明
enabled boolean true 插件是否默认启用。设为 false 时插件加载但不激活，需手动调用 enable()。
🔮 未来可扩展选项（当前版本未实现）
customPatterns Array [] 自定义填充模式列表，用于扩展内置的序列识别规则。
maxFillSize number 10000 最大填充数量限制，防止误操作填充过多单元格。
animationDuration number 200 填充动画时长（毫秒）。
配置示例： 
pluginOptions: {
    autoFill: {
        enabled: true,
        // 未来扩展：
        // customPatterns: [...],
        // maxFillSize: 10000,
        // animationDuration: 200,
    }
}

🏗️ 架构设计

┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  AutoFillPlugin   │ →  │ AutoFillStrategy │ →  │  EventHandler    │
│  (生命周期管理)   │    │  (交互逻辑)      │    │  (事件分发)      │
└─────────────────┘    └──────────────────┘    └─────────────────┘
        ↓                       ↓                      ↓
   BasePlugin              优先级: 90            canvas/document
   (标准接口)            MouseStrategy(50)      DOM事件监听
                          ResizeStrategy(100)

状态机:  idle → hover(悬停手柄) → dragging(拖拽中) → fill(执行填充) → idle
